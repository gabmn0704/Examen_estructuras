# Caso de Estudio 3 — TypeScript

Proyecto web con React + Vite + TypeScript.

## Ejecutar en Sublime Text
1. Instala Node.js LTS.
2. Abre esta carpeta en Sublime.
3. Abre CMD dentro de la carpeta.
4. Ejecuta `npm install`.
5. Ejecuta `npm run dev`.
6. Abre la dirección que muestre Vite (normalmente http://localhost:5173).

**Importante:** no abras `index.html` con doble clic. El proyecto funciona mediante Vite.
